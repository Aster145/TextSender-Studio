# 执行位置采样基准

手动运行（不作为 CI 的时间阈值断言）：

```powershell
dotnet run --project tests/ExecutionPosition.Bench/ExecutionPosition.Bench.csproj -c Release
```

同一份预先编译的字节码比较三个模式：无观察器、有观察器但不读取行号、观察器加每 100 ms 读取一次行号。每组先预热三轮，再交错运行七轮，输出中位数、范围和相对差值。

计算负载为 200 万次循环；等待负载为 20 次模拟宿主等待，每次 `Thread.Sleep(20)`。系统计时粒度可能使等待总时长超过 400 ms，但三种模式执行相同负载。

这是当前解释器的局部基准，排除了编译和 WPF 高亮绘制，也不访问真实设备。不能用它保证实际脚本或整台电脑的耗时；小幅正负差值应结合样本范围看待。关闭显示仍保留宿主调用和已有执行预算边界处的轻量位置快照，以便等待期间随时打开显示，界面无需逐指令接收事件。
