# TextSender Studio 0.2.0

- 调整三个标签页、设置与资源管理窗口的布局、控件与字号；HTTP 保存和执行操作固定在底部。
- HTTP 动作默认锁定，可打开编辑开关后增删步骤、上移或下移；切换时保存有效修改，无效输入保留草稿。
- HTTP 请求使用完整 URL，可按步骤控制不同设备；主脚本可直接使用 `HTTP_GET` / `HTTP_POST` / `HTTP_REQUEST`，不需新增动作或设备配置。保留旧相对路径配置。
- 脚本编辑增加补全、行号、自动缩进、多行缩进和双击 / F12 函数跳转。
- 增加可展开的语法说明，示例可复制或插入。
- 增加项目声音提醒函数，可播放系统提示音或本地音乐，文件播放支持停止。
- 接入 EasyCon 的 `ALERT` 推送，支持 PushPlus、Bark 和自定义 Webhook，在全局设置中配置。

更新只替换程序 EXE，保留已有 `settings.json` 与 `projects/`。源码提交不包含个人配置、推送密钥、项目、日志或编译产物。
