# TextSender Studio 0.3.0

- 分为主脚本、发送文字、图像标签、HTTP 动作四个标签页，分别使用紫、蓝、青绿、橙色。文字草稿与脚本独立保存，切换项目分别载入。
- 顶部常驻“窗口置顶”和“打开项目目录”。手动控制开关移到主界面，并保存显示偏好。
- 编辑器增加语法高亮、缩进引导线、代码块折叠；保存和 Ctrl+S 自动整理脚本缩进，普通文字保留原文。
- “显示执行位置”在编辑区高亮当前行；默认关闭，运行中可随时开关，每秒最多刷新 10 次。执行进入折叠块会展开，修改运行中的源码后暂时隐藏旧位置。
- 支持中文函数名，包括项目动作、脚本定义、补全和双击跳转。
- HTTP 动作以函数名为主标题，原名称改为下方可选说明；双击动作执行。运行时锁定图像标签与 HTTP 动作编辑，结束后恢复。
- 对照 EasyCon 补齐 14 个 Pro 按钮、8 向方向键和双摇杆；按任天堂布局排列。
- 新增手柄控制窗口：屏幕按住操作、可保存的键盘映射、XInput 实体手柄直控，支持组合输入；失焦即暂停并释放。
- 新增录制脚本：记录已发送并确认的手柄状态及毫秒等待，结束后插入主脚本，支持保存、编辑及回放。使用 Studio `PAD_STATE` 扩展保留模拟摇杆幅度与组合键。

只替换 EXE 即可更新，保留 `settings.json` 和 `projects/`。源码发布不包含用户配置、项目、日志或编译文件。此版不改动单片机固件。

自动检查使用模拟设备、本机回环 HTTP 和合成图像；通过测试不等于实体 Switch、手柄或网络条件下的输入效果已验证。执行位置基准只测 VM 与 10 Hz 位置读取，不包含 WPF 绘制及设备通信。
