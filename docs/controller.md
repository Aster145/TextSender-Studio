# 手柄控制与录制

主脚本页点击“手柄 / 键盘控制”。窗口打开时保持暂停，点击“开始控制”后才开始输入；主界面的“录制脚本”会打开窗口并在获得焦点后开始控制和录制。切换到其他窗口、打开映射设置、暂停、关闭或通信错误均停止输入并释放状态；回来后手动点击“开始控制”继续。

屏幕按钮按住即保持，松开即释放；可与键盘、实体手柄组合。支持 EasyCon 定义的 A/B/X/Y、L/R/ZL/ZR、MINUS/PLUS、LCLICK/RCLICK、HOME/CAPTURE，8 向方向键，以及左右摇杆的 8 向和回中。内联手动栏提供点击指定时长，完整的持续控制和双摇杆在控制窗口中操作。

## 键盘映射

勾选“键盘映射”，点击“设置键盘映射”修改并保存。默认沿用 EasyCon：

| 控制 | 默认电脑按键 |
| --- | --- |
| A / B / X / Y | L / K / I / J |
| L / R / ZL / ZR | G / T / F / R |
| 左摇杆上 / 下 / 左 / 右 | W / S / A / D |
| 右摇杆上 / 下 / 左 / 右 | 方向键 |
| LCLICK / RCLICK | Q / E |
| HOME / CAPTURE | C / Z |
| PLUS / MINUS | 小键盘加 / 减 |

支持同时按多个键；相反方向相互抵消。未设置的方向或动作可以自行绑定。键盘输入只在控制窗口获得焦点并启用后捕获，普通快捷键不会传给其他程序；Windows 安全组合键由系统保留。向 Switch 直接输入键盘字符请使用独立的“键盘直通”，它与键盘映射为手柄是两种不同用途。

## 实体手柄

启用“实体手柄 · XInput”，选择 1–4 号手柄。Xbox 或支持 XInput 模式的手柄可使用；仅提供 DirectInput 的设备不在此输入接口范围内。默认按任天堂物理位置交换 AB/XY，也可取消该选项。支持双模拟摇杆、扳机、肩键、方向键、摇杆按下及开始/返回键。标准 XInput 不提供 HOME/CAPTURE，这两个键仍可通过屏幕或键盘映射输入。

## 录制与回放

在控制窗口开始或停止录制。停止录制、暂停或失焦后，将已确认发送的动作插入主脚本，不自动执行；用 Ctrl+S 保存。录制以毫秒记录状态变化，组合键与模拟摇杆坐标不会被转换成单键或满幅方向。

```text
PAD_STATE "", 128, 128, 128, 128
WAIT 100
PAD_STATE "A+LCLICK+UPLEFT", 160, 96, 128, 128
WAIT 200
PAD_STATE "", 128, 128, 128, 128
```

`PAD_STATE` 是 Studio 提供的完整状态函数，参数为按键名称、左 X、左 Y、右 X、右 Y。坐标范围 0–255，128 为中心。原 EasyCon 摇杆语法不能表达所有模拟幅度，因此此录制扩展不能直接在未加入它的上游 EasyCon 中运行。它可以在 Studio 内与原 `A DOWN`、`A UP`、`LS UP` 等语法混用。

按键列表和默认键盘映射参考 EasyCon 的 `ICGamePad.cs`、`SwitchCommand.cs`、`KeyMappingConfig.cs`；实体手柄位置映射参考 `GamepadMapper.cs`，录制流程参考 `OperationRecords.cs`。上游版本与许可见 [EasyCon 来源说明](../vendor/EasyCon.Script/NOTICE.md)。
