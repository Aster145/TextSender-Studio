# TextSender Studio 0.3.1

- 修复编辑器回车后光标跳回行首的问题；换行后位于下一行的正确缩进处。输入完整命令后按回车正常换行，未完成的补全仍先接受建议。
- 主脚本增加“允许编辑”开关，默认锁定。关闭开关保留未保存的内容，运行时暂时锁定，结束后恢复编辑偏好。
- 脚本与文字草稿分别显示红色“未保存”、绿色“已保存”；撤销回已保存内容会恢复绿色。
- 增加批量注释、取消注释按钮；`Ctrl+/` 切换注释，`Ctrl+Shift+/` 取消注释。保留缩进，支持折叠区域和单次撤销。
- “画面与识图”整体移动到“图像标签”。主脚本右侧改为输出框，只显示开始、结束、PRINT 和 ALERT；完整执行日志移入设置，运行时也可查看。
- 标签制作采用 EasyCon 的双选区流程：打开图片/截图、框选搜索范围与目标、坐标调整、预览、测试后保存。保留原图以便重新编辑，标签包可携带原图。
- 标签支持六种图像匹配方法及可组合的灰度、二值化、高斯模糊。默认相关系数算法保持原阈值含义；OCR 尚未接入。

本版不改动单片机固件。更新只替换 EXE，保留已有设置与项目；GitHub 仅发布源码，不含编译文件及个人配置。

验证使用合成图像、隔离项目、模拟输入与通知服务。已验证实际 WPF 回车事件及编辑交互；实体 Switch、采集卡和外部推送效果不包含在自动检查中。
