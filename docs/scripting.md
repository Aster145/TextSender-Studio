# 脚本与函数

TextSender Studio 使用 EasyCon 的实际词法分析器、编译器和 ECX 托管解释器。等待和输入时长均为**毫秒**；`WAIT 0` 立即继续。脚本在后台执行，“停止”取消等待与运行，手柄保持状态在结束时释放。

## 已接入的语法与能力

- EasyCon 变量、算术/比较/逻辑表达式、数组、字符串、类型和函数语法。
- `IF / ELIF / ELSE / ENDIF`、`FOR / NEXT`、`WHILE / UNTIL`、`BREAK / CONTINUE`。
- `FUNC / ENDFUNC / RETURN` 和 `CALL`，参数及返回值按 EasyCon 规则解析。
- `WAIT`、普通手柄按键、`DOWN / UP` 保持状态、左右摇杆及定时回中。
- `PRINT` / `ALERT` 显示在主脚本的输出框，输出框只显示开始、结束及这两类消息；`ALERT` 同时调用设置中启用的推送服务。支持 `TIME`、`RAND` 和解释器的内建运算。
- `@标签名` 调用当前项目的图像标签，返回整数匹配度 **0–100**。标签的图片、搜索范围和匹配方式在“图像标签”中设置。
- 当前项目的常用短语、启动脚本、HTTP 动作和声音提醒作为无参数函数，用 `CALL 函数名` 调用。

这是语言语法兼容和上述宿主能力的接入，并不等于支持 EasyCon 的所有硬件与扩展。Amiibo、OCR、ONNX 推理、`FRAME` / `ROI` 图像对象函数、脚本文件句柄 API、交互式标准输入和外部 DLL 的原生函数尚未接入；执行到它们会报告不支持。多文件模块和旧版 `.IL` 标签格式不在本版导入范围内。

## 基础脚本

```text
# 单位为毫秒
WAIT 500
A 100

$score = @完成提示
PRINT 匹配度: & $score
IF $score >= 90
    PRINT 找到目标图片
ELSE
    PRINT 未找到目标图片
ENDIF
```

按住并同时组合多个键：

```text
L DOWN
R DOWN
WAIT 100
L UP
R UP
```

摇杆使用原 EasyCon 语法，例如 `LS UP,100`，表示向上推左摇杆 100 ms 后回中。状态保持需要当前设备连接支持完整手柄状态；不支持时会报告错误。

## 项目动作函数

在相应管理页面设置唯一的函数名，再通过“插入函数”插入调用：

```text
CALL phrase_hello
CALL start_tools
CALL robot_tap
```

这些函数不需要在脚本中重复写 `FUNC`。运行前由 Studio 注册为当前项目的外部动作，按顺序执行。启动脚本是否等待退出由对应快捷脚本设置决定。未配置的函数名会在编译时报告错误。

函数名支持中文、其他 Unicode 字母、数字和下划线，不能以数字开头；四个动作分类共用命名空间。例如 `CALL 短按电源`。不要与脚本中已定义的函数、`SEND_TEXT`、`KEYBOARD`、`PAD_STATE`、`HTTP_GET`、`HTTP_POST`、`HTTP_REQUEST` 或语言内建函数重名。HTTP 动作的说明可以留空或重复，函数名必须唯一。

## 直接发送 HTTP

也可以直接在脚本中写完整 URL，不必保存 HTTP 动作或填写默认设备：

```text
HTTP_GET "http://192.168.1.50/api/cmd?cmd=shortpress"
WAIT 500
HTTP_POST "http://192.168.1.60/control", "{\"on\":true}"
HTTP_REQUEST "PUT", "https://device.example/api/state", "ready", "text/plain"
```

`HTTP_GET` 接受 URL；`HTTP_POST` 接受 URL 和 JSON 正文；`HTTP_REQUEST` 接受方法、URL、正文和 Content-Type。方法支持 GET / POST / PUT / PATCH / DELETE / HEAD。每条指令可以指向不同的设备、域名和端口，超时使用全局 HTTP 超时设置。请求失败会停止本次脚本；示例地址需替换成自己的设备和接口。

## 编辑器

主脚本默认锁定，打开“允许编辑”后可输入、加载和插入代码。关闭开关保留未保存的改动，不自动保存或丢弃。脚本和文字草稿分别用红色“未保存”、绿色“已保存”提示；撤销回已保存内容也会恢复绿色。运行期间锁定编辑，结束后恢复开关选择。

主标签的“语法说明与示例”可展开查看，并将示例插入光标处。编辑器显示行号和当前位置，输入命令时提供补全；`Ctrl+Space` 手动打开建议，方向键选择，`Enter` 或 `Tab` 接受，`Esc` 关闭。

选中多行后点击“批量注释”或“取消注释”。`Ctrl+/` 切换注释，`Ctrl+Shift+/` 取消注释；以缩进后的 `#` 为标记，跳过空行，支持一次撤销。折叠块按完整源码处理。

`Enter` 自动延续缩进并识别条件、循环和函数块；`Tab` / `Shift+Tab` 可调整选中多行的缩进。双击函数名或按 `F12` 跳到脚本内定义，或打开对应短语、启动脚本、声音提醒、HTTP 动作；图像标签也可跳到其详情。

关键字、字符串、数字、变量和注释使用不同颜色，缩进引导线显示层级。点击行号旁的标记折叠代码块；折叠只改变显示，保存和运行仍使用完整源码。编辑开启时点击“保存”或按 `Ctrl+S` 自动以 4 空格整理缩进，使 `NEXT` 与 `FOR`、`ENDIF` 与 `IF` 对齐，保留字符串和注释内容。独立“发送文字”页的 Ctrl+S 保存原文，不调整缩进。

打开“显示执行位置”后，编辑区高亮当前执行行并在必要时滚动、展开代码块；默认关闭，偏好自动保存。每秒最多刷新 10 次，关闭时停止界面轮询。快速语句可能被采样跳过；`WAIT` 或设备动作期间显示正在等待的源代码行。运行期间主脚本、图像标签与 HTTP 动作均锁定，结束后恢复编辑偏好。设备通信与错误详情在“设置 → 执行日志”中查看；运行中打开设置会直接显示日志并暂时锁定常规设置。

手柄录制和 `PAD_STATE` 完整状态扩展见 [手柄控制与录制](controller.md)。

## 声音与推送

在主标签点击“声音提醒”，为当前项目新增函数，选择 Windows 系统提示音或本地音乐文件（MP3 / WAV / WMA）。系统提示音使用 Windows 当前声音方案；音乐文件播放一次，播放结束后继续脚本，点击“停止”会停止播放。音乐文件保留在所选位置，移动项目时应一并保留该文件，也可使用相对于项目目录的路径。

```text
CALL sound_notice
BEEP 800, 200
ALERT 操作完成
```

`sound_notice` 需先创建。`BEEP` 使用频率（Hz）和时长（ms）。`ALERT` 保留 EasyCon 的字符串拼接语法，例如 `ALERT 已完成 & $count & 次`。

在“设置 → 推送服务”中启用并配置 PushPlus、Bark 或自定义 Webhook，可同时启用多个服务。支持 EasyCon 原有的 `{{token}}`、`{{title}}`、`{{content}}` 及自定义变量，GET / POST、请求头与正文。URL 中变量会编码，JSON 字符串中的变量会转义；JSON 占位符应放在引号内。超时单位为毫秒；推送失败写入执行日志，不自动重发。未启用服务时 `ALERT` 只写日志。

推送凭据保存在本机 `settings.json`，不进入源码仓库。不要将自己的设置文件随项目公开分享。

## HTTP 步骤编辑

“HTTP 动作”默认只读。打开“允许编辑”后，可修改动作、点“新增一行”、删除选中行、上移或下移。表格顺序就是执行顺序，不支持按列排序。关闭编辑、切换动作或项目时保存有效修改；输入无效时保留草稿并提示修正。关闭编辑仍可执行动作或插入函数。

每一步可以直接填写完整地址，例如 `GET http://192.168.1.50/api/cmd?cmd=shortpress`，后续步骤可指向另一个设备。支持 HTTP / HTTPS、域名和自定义端口，无需另外配置动作的默认地址。已有 `/api/...` 相对路径继续使用设置中的默认 HTTP 设备。请求正文和 Content-Type 位于步骤下方的可展开区域。

## 文字和键盘扩展

Studio 新增两个使用 EasyCon 函数调用语法的宿主函数：

```text
SEND_TEXT "Hello"
KEYBOARD "CTRL+S", 50
```

`SEND_TEXT` 使用全局设置的发送等待、逐字间隔和换行等待。`KEYBOARD` 第二个参数为按键持续毫秒数。输入内容和按键能否被目标接受，取决于固件支持的字符映射与目标应用。

## 保存与错误

主脚本保存在当前项目目录（默认 `main.ecs`）；启动脚本可放在项目的 `scripts` 子目录。可以加载、编辑、保存，并在运行前检查语法。错误信息尽可能显示原始脚本行号；缺失标签、设备错误和 HTTP 错误会停止当前执行并写入日志，不会自行重试不确定的设备动作。
