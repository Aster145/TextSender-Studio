# 键盘直通与 UART 备用连接

## 键盘直通

打开“键盘直通”窗口后，点击“开始直通”。只有该窗口处于前台时才捕获键盘：普通 Windows 快捷键会被拦截，按键报告发往目标设备。Windows 的安全组合键仍由系统处理。

支持最多 6 个普通键与 8 个左右修饰键同时按下。超出的普通键会提示并忽略，松开后重按即可；程序不记录按键对应的输入文字。

- 切换到其他窗口时，立即停止捕获、丢弃尚未发送的旧按键，并请求释放目标按键。
- 回到直通窗口后点击“开始直通”继续。
- 暂停、关闭窗口、发送失败或队列已满时均停止发送并请求释放。
- 队列保留按下/释放顺序，不会把快速短按合并成空状态。串口与 Wi-Fi 连接器分别负责续租，断线时由固件的超时释放机制兜底。

## UART 备用方式

`SerialInputBridge` 用于原来的 TextKeyboard 固件，通过电脑连接 UART 串口，波特率为 115200。它支持：

- `PING` 固件识别。
- `TYPE2` 发送 ASCII、Tab 和换行；正文超过 8192 字节时自动分块。
- `HID` 原始键盘报告、组合键和 `HID OFF` 释放。
- 原始按键保持期间，每 200 ms 续传当前状态；原固件的 HID 超时为 1000 ms。
- 取消正文时发送 Control-X，并等待取消响应。

UART 旧固件只提供键盘，**不支持 Pro 手柄或 Wi-Fi 配网**，相关操作会提示切换到新版 Wi-Fi 固件。旧串口固件的逐字间隔范围为 1–1000 ms，换行等待为 0–3000 ms；“发送前等待为 0”仍表示立即开始。

串口不会在构造连接器时打开；首次状态检查或输入操作才打开。停止操作会保持正常的串口连接，关闭连接器时释放并关闭串口。

## 离线检查

```powershell
dotnet run --project tests/TextSenderStudio.Input.Checks -c Release
```

检查使用模拟桥接器与串口传输，不安装全局键盘 Hook，不打开实体串口。覆盖按键队列、失焦清理、错误停止、组合键映射、TYPE2/HID 协议与取消响应。
